# 什么时候会问你

这张表由 `node scripts/ask-table.mjs` 打印，每一行都是用真正的判断代码在三个档位下跑出来的；自测会核对它，规则有变动时这里会跟着变。

| 这一步 | 谨慎 | 标准 | 放手 |
|---|---|---|---|
| 读文件 | 直接做 | 直接做 | 直接做 |
| 写文件（工作区里） | 直接做 | 直接做 | 直接做 |
| 只是看的命令（dir） | 问你 | 直接做 | 直接做 |
| 手机：看屏幕 | 直接做 | 直接做 | 直接做 |
| 手机：普通的点（下一步） | 问你 | 问你 | 直接做 |
| 手机：底部一排里的「发布」入口 | 问你 | 问你 | 直接做 |
| 手机：点「发布笔记」，你没说过发 | 问你 | 问你 | 问你 |
| 手机：点「发布笔记」，你说过「发」 | 直接做 | 直接做 | 直接做 |
| 手机：点「发送」，你说过「必须发出去」 | 直接做 | 直接做 | 直接做 |
| 给你看要发的草稿，你没说过发 | 问你 | 问你 | 问你 |
| 手机：点「发布笔记」，你刚在草稿卡上点了允许 | 直接做 | 直接做 | 直接做 |
| 手机：点「立即支付」，你说过「发」 | 问你 | 问你 | 问你 |
| 手机：点「删除」，你说过「发」 | 问你 | 问你 | 问你 |
| 手机：点「同意并继续」 | 问你 | 问你 | 问你 |
| 手机：别人填到一半时点「退出」 | 问你 | 问你 | 问你 |
| 手机：没有半成品时点「退出」 | 问你 | 问你 | 直接做 |

说明：

- 「你说过发」指你本人在聊天或群里说了「发」「发吧」「可以排」「必须发出去」这类话，2 小时内有效；说「先别发」就收回。
- 你在草稿卡片上点了「允许」，等于对这件事说了「发」：之后在手机上点「定时发布」「发布」不再问。
- 付款、删除、点同意、丢掉别人填到一半的内容，无论什么档位、说没说过「发」，都会问。
- 「标准」档下，对某个 App 点过「以后都允许」之后，那个 App 里的普通点击不再问。
