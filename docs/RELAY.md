# 不用 Tailscale 连回家：用你自己的云服务器中转

家里的电脑一般在路由器后面，外面的手机找不到它。Lamplit 可以把你的一台云服务器做成**中转**：
家里的电脑主动连上中转，手机在外面（用流量）连中转，中转把**加密的数据原样**转给电脑。
不用装 Tailscale，不用改路由器。

**试验功能，默认关闭**：在「设置 → 手机和外网」里装了中转才会打开。目前支持 Lamplit 安卓 App。iPhone 和普通浏览器要等有域名的版本（没有域名时证书是电脑自己签的，
只有 App 能按指纹认）。

---

## 1. 装

要一台有公网 IP 的 Linux 云服务器（腾讯云轻量、CVM、阿里云 ECS 等都行），和它的 SSH 账号
（root，或能 sudo 的账号）。

1. 在家里那台电脑的 Lamplit 里打开 **设置 → 手机和外网**，找到「出门在外：用你的云服务器中转」。
2. 填服务器的公网 IP、SSH 用户名和密码，点「在这台服务器上装中转」。约 10 秒装好。
   - SSH 密码只用这一次，不保存。
   - 中转装成一个独立的 systemd 服务 `lamplit-relay`，用临时账号运行，只能写自己的数据目录
     （`/var/lib/private/lamplit-relay`），程序在 `/opt/lamplit-relay`。
3. 装好后这台电脑自动打开「通过中转连接」，并从电脑这边试一下端口通不通。
4. **放行端口**（只有你能做，在云服务器控制台里）：默认 TCP 34443，来源 0.0.0.0/0。
   - 腾讯云轻量应用服务器：实例详情 →「防火墙」→ 添加规则。
   - 腾讯云 CVM：「安全组」→ 入站规则 → 添加规则。
   - 阿里云 ECS 等：也是「安全组」。

   服务器自己的防火墙（ufw / firewalld）装的时候已经放行了。放行后点「再测一次」。
5. 在 **设置 → 手机和外网** 点「显示二维码」，用手机 App 扫一次。以后在家走局域网，出门自动走中转。
   App 的机器列表里会写当前走的是「局域网」还是「中转」，中转慢时写「中转 · 较慢」。

**其他机器**：之后用「添加机器」装的机器会自动连上同一个中转（各有自己的编号和证书）。已经加好的机器，
点「让其他机器也用这个中转」。如果中转所在的那台云服务器上也装了 Lamplit，它也会自动连上（在服务器内部
连 127.0.0.1）。机器之间的协作、推更新，在局域网和 Tailscale 都不通时也会走中转。

**重装、换端口**：点「重装 / 换端口」，在同一台服务器上再装一次。加入密码和已登记的电脑都保留。
换了端口的话，记得在控制台放行新端口；手机要在家（同一个 Wi-Fi）打开一次 App 或重新扫码，才会记下新端口。

## 2. 中转看得到什么

- 手机和电脑之间是 TLS 加密的。加解密只在手机和电脑上做，**证书的私钥只在你的电脑上**
  （`data/relay-tls/`）。中转只读 TLS 握手里的电脑编号（SNI）来决定转给谁，不解密。
- 中转看得到：哪台电脑（一个随机编号）、谁（来源 IP）、什么时候、多少流量。
- 中转看不到：对话、文件、屏幕画面、配对令牌、设备登录。
- 手机只认配对时二维码里带的这台电脑的证书指纹：中转或别人冒充这台电脑，手机不会连。
- 电脑也只认装中转时记下的中转证书：换了一台冒充的中转，电脑不会把密钥交过去。
- 能不能操作电脑，仍然看配对。从中转进来的请求都算外网：8 位配对码不能用，只认扫码配对过的设备；
  「只有你能批准」的事（改权限、审批、密钥）也不能从这里做。
- 谁能用这个中转：电脑第一次登记要「加入密码」（装中转时生成，只在你的机器之间传），之后凭电脑自己的密钥。
  中转按来源 IP 限流，乱试编号的 IP 会被封 10 分钟。

## 3. 怎么断开、撤销

| 想做的 | 做法 |
| --- | --- |
| 马上断开这台电脑 | 设置 → 手机和外网，关掉「通过中转连接」 |
| 不让某台手机再连 | 设置 → 手机和外网 →「已连接的设备」里移除它 |
| 不要这个中转了 | 点「卸载中转」（要 SSH 密码）：服务、程序、数据都删掉，这台电脑和用它的机器都断开。再到云服务器控制台删掉放行端口的规则 |
| 手动卸载 | 在服务器上 `sudo systemctl disable --now lamplit-relay`，删 `/opt/lamplit-relay`、`/var/lib/private/lamplit-relay`、`/etc/systemd/system/lamplit-relay.service` |

## 4. 和「国内中转（给 Tailscale 用）」的区别

**设置 → 机器** 里的「国内中转」是给 **Tailscale** 用的（Tailscale 的 DERP 中转），前提是手机和电脑都装了
Tailscale。这里的中转是 Lamplit 自己的，不需要 Tailscale（目前是试验功能，默认关闭）。两个可以装在同一台服务器上，端口不同
（Tailscale 中转 33445，Lamplit 中转 34443）。

## 5. 旧版 App

只开了中转（电脑没有局域网地址）时，二维码以一句话开头：「请先更新 Lamplit App 再扫」。旧版 App 扫到会提示
「不是 Lamplit 的连接码」，不会再在列表里留下一台永远离线的机器；更新 App 后再扫即可。
