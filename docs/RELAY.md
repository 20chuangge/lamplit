# 不用 Tailscale 连回家：用你自己的云服务器中转

家里的电脑一般在路由器后面，外面的手机找不到它。Lamplit 可以把你的一台云服务器做成**中转**：
家里的电脑主动连上中转，手机在外面（用流量）连中转，中转把**加密的数据原样**转给电脑。
不用装 Tailscale，不用改路由器。

**试验功能，默认关闭**：在「设置 → 手机和外网」里装了中转才会打开。目前支持 Lamplit 安卓 App。iPhone 和普通浏览器要等有域名的版本（没有域名时证书是电脑自己签的，
只有 App 能按指纹认）。

---

## 1. 装

要一台有公网 IP 的 Linux 云服务器（腾讯云轻量、CVM、阿里云 ECS 等都行），和它的 SSH 账号
（root，或能 sudo 的账号）。中转用 **Node.js 20 或更新** 运行，不用你先装：用「添加机器」装过 Lamplit
的服务器已经有了；没有（或太旧）的话，安装时会自动装上（1.5.51）。

- 先用系统自己的软件源：版本够 20 就直接装它（例如 Debian 13；Rocky / AlmaLinux / RHEL 8–9 用
  AppStream 里的 `nodejs:22` 模块）。
- 系统自带的太旧（例如 Ubuntu 22.04 / 24.04、Debian 12）就加 [NodeSource](https://github.com/nodesource/distributions)
  的 Node.js 22 软件源（Node.js 官网列出的 Linux 软件源）。软件包有 NodeSource 的签名：apt 用 `Signed-By`、
  dnf / yum 用 `gpgcheck=1` 先验证再装，不运行网上下载的脚本。
- 支持自动装的系统：Ubuntu、Debian、Rocky、AlmaLinux、CentOS、RHEL、TencentOS、OpenCloudOS、Alibaba Cloud Linux
  （x86_64 或 arm64）。别的系统会停下，建议在云服务器控制台重装成 Ubuntu 24.04，或者先自己装好 Node.js 20 或更新。装的细节记在服务器的 `/tmp/lamplit-node-install.log`。
- 装的过程会显示在 Lamplit 的进度里（「正在安装 Node.js…」→「Node.js v22.x 装好了」），慢的服务器可能要几分钟。

> 给小白的版本（三种方式怎么选、一步步怎么做、直连没打通查什么）在官网文档的
> [「在外面也能用」](https://20chuangge.github.io/lamplit/docs.html#outside)。这里是完整说明。

1. 在家里那台电脑的 Lamplit 里打开 **设置 → 手机和外网**，找到「出门在外：用你的云服务器中转」。
2. 填服务器的公网 IP、SSH 用户名和密码，点「在这台服务器上装中转」。一般约 10 秒装好；要先装 Node.js 的话要几分钟（进度里会写「正在安装 Node.js…」）。
   - SSH 密码只用这一次，不保存。
   - 中转装成一个独立的 systemd 服务 `lamplit-relay`，用临时账号运行，只能写自己的数据目录
     （`/var/lib/private/lamplit-relay`），程序在 `/opt/lamplit-relay`。
3. 装好后这台电脑自动打开「通过中转连接」，并从电脑这边试一下端口通不通。
4. **放行端口**（只有你能做，在云服务器控制台里）：默认 TCP 34443，再加一条 **UDP 34443**（直连用，见第 5 节），来源都是 0.0.0.0/0。
   - 腾讯云轻量应用服务器：实例详情 →「防火墙」→ 添加规则。
   - 腾讯云 CVM：「安全组」→ 入站规则 → 添加规则。
   - 阿里云 ECS 等：也是「安全组」。

   服务器自己的防火墙（ufw / firewalld）装的时候已经放行了（TCP 和 UDP）。放行后点「再测一次」。
5. 在 **设置 → 手机和外网** 点「显示二维码」，用手机 App 扫一次。以后在家走局域网，出门自动走中转（能直连时走直连）。
   App 的机器列表里会写当前走的是「局域网」「直连」还是「中转」，中转慢时写「中转 · 较慢」（见第 5 节「怎么知道直连了」）。

**其他机器**：之后用「添加机器」装的机器会自动连上同一个中转（各有自己的编号和证书）。已经加好的机器，
点「让其他机器也用这个中转」。如果中转所在的那台云服务器上也装了 Lamplit，它也会自动连上（在服务器内部
连 127.0.0.1）。机器之间的协作、推更新，在局域网和 Tailscale 都不通时也会走中转。

**重装、换端口**：点「重装 / 换端口」，在同一台服务器上再装一次。加入密码和已登记的电脑都保留。
换了端口的话，记得在控制台放行新端口；手机要在家（同一个 Wi-Fi）打开一次 App 或重新扫码，才会记下新端口。

## 2. 中转看得到什么

- 手机和电脑之间是 TLS 加密的。加解密只在手机和电脑上做，**证书的私钥只在你的电脑上**
  （`data/relay-tls/`）。中转只读 TLS 握手里的电脑编号（SNI）来决定转给谁，不解密。
- 中转看得到：哪台电脑（一个随机编号）、谁（来源 IP）、什么时候、多少流量。
- 中转看不到：对话、文件、屏幕画面、配对令牌、设备登录。
- 手机只认配对时二维码里带的这台电脑的证书指纹：中转或别人冒充这台电脑，手机不会连。
- 电脑也只认装中转时记下的中转证书：换了一台冒充的中转，电脑不会把密钥交过去。
- 能不能操作电脑，仍然看配对。从中转进来的请求都算外网：8 位配对码不能用，只认扫码配对过的设备；
  「只有你能批准」的事（改权限、审批、密钥）也不能从这里做。
- 谁能用这个中转：电脑第一次登记要「加入密码」（装中转时生成，只在你的机器之间传），之后凭电脑自己的密钥。
  中转按来源 IP 限流，乱试编号的 IP 会被封 10 分钟。

## 3. 怎么断开、撤销

| 想做的 | 做法 |
| --- | --- |
| 马上断开这台电脑 | 设置 → 手机和外网，关掉「通过中转连接」 |
| 不让某台手机再连 | 设置 → 手机和外网 →「已连接的设备」里移除它 |
| 不要这个中转了 | 点「卸载中转」（要 SSH 密码）：服务、程序、数据都删掉，这台电脑和用它的机器都断开。再到云服务器控制台删掉放行端口的规则 |
| 手动卸载 | 在服务器上 `sudo systemctl disable --now lamplit-relay`，删 `/opt/lamplit-relay`、`/var/lib/private/lamplit-relay`、`/etc/systemd/system/lamplit-relay.service` |
| 不想直连，全走中转 | 设置 → 手机和外网，关掉「先试直连」：已经直连的马上断开，之后都走中转 |

## 4. 和「国内中转（给 Tailscale 用）」的区别

**设置 → 机器** 里的「国内中转」是给 **Tailscale** 用的（Tailscale 的 DERP 中转），前提是手机和电脑都装了
Tailscale。这里的中转是 Lamplit 自己的，不需要 Tailscale（目前是试验功能，默认关闭）。两个可以装在同一台服务器上，端口不同
（Tailscale 中转 33445，Lamplit 中转 34443）。

## 5. 直连（1.5.46）

手机在外面连家里的电脑时，**先照常走中转**，同时在后台试着让两边直接连上（「打洞」）。打通了，之后的新连接
直接走，数据不经过服务器：看屏幕快一些，也不占云服务器的带宽和流量。打不通就一直走中转，和以前一样。

- **开关**：设置 → 手机和外网 →「先试直连（打不通自动走中转）」，默认打开。中转装在哪台服务器上，那台
  服务器上的 Lamplit 不试直连（两种走法都只经过它一次，省不了什么）。
- **要中转是新版**：中转顺带回答「你在公网上看起来是什么地址」（STUN），用的是同一个端口号的 **UDP**。
  1.5.46 之前装的中转要点一次「重装 / 换端口」更新，并在云服务器控制台放行 **UDP 34443**。不更新也能用，都走中转。
- **怎么知道直连了**（1.5.48 起照实写走的是哪条路）：
  - App 的机器列表、页面左上角机器名下面那一行：同一个 Wi-Fi 写「局域网」，在外面打通了写「直连」，
    没打通写「中转」；打开的就是装着中转的那台服务器时写「经中转（中转就在这台上）」，这是对的。
  - 手机上 设置 → 关于 →「手机到这台」：现在走哪条路、在不在试、上次没打通的原因、下次什么时候再试（只在 App 里，不显示地址）。
  - 电脑上 设置 → 手机和外网 的中转卡片写着哪台设备在直连（只写名字）；
    体检里有一行「直连」（打不通只是说明，不算问题），改了防火墙后点「重新体检」会马上重新测。
- **安全**：
  - 只有配对过的设备能直连：交换地址要带设备令牌，中转没法把陌生设备介绍进来。
  - 双方的地址和一半密钥，装在已经认过电脑证书指纹的加密连接里交换，中转只看到密文。
  - 直连的通道本身加密（AES-256-GCM，双方各出一半随机数），里面跑的仍是和中转时完全一样的 TLS：手机仍只认这台电脑的证书。
  - 从直连进来的请求和中转一样算外网：8 位配对码不能用，「只有你能批准」的事也不能从这里做。
  - 电脑只开一个随机的 UDP 端口，不认识的包一律不理；路由器不用设置。
- **什么时候打不通**（这些时候都走中转，照样能用）：
  - 云服务器控制台没放行 **UDP** 34443：体检「直连」一行会写「还差一步」。
  - 中转是 1.5.46 之前装的：体检写「中转要更新一次」，点一次「重装 / 换端口」。
  - 电脑上的 **Windows 防火墙**挡住了 Lamplit（第一次弹窗时点了取消，Windows 会留下一条「阻止」规则）：
    设置 → 手机和外网 出现提示时点「修复防火墙」；或者在「高级设置 → 入站规则」里删掉名字是 Lamplit 的阻止规则。
  - 电脑上的代理软件开着 **TUN（虚拟网卡）模式**（Clash 等），把 UDP 接走了：在代理规则最前面加
    `PROCESS-NAME,Lamplit.exe,DIRECT`，或者暂时关掉 TUN 模式。
  - 两边都是「对称型 NAT」（手机流量常见），或者网络封了 UDP（有的公司、酒店网络）。
- **换网络**（Wi-Fi 换 4G）：直连断开，新连接马上走中转，过一会儿再试直连。正在看的屏幕会断一下再自动重连。
- **机器之间**：电脑经中转连别的机器时（局域网和 Tailscale 都不通），也会先试直连。桌面窗口打开一台只有中转能到的机器时也一样（1.5.47）。

## 6. 中转自己更新（1.5.47）

中转会跟着 Lamplit 一起更新，不用再填 SSH 密码。

- **怎么更新**：你的电脑连上中转时，会告诉它「我这里有中转的新版」。中转经过这台电脑的隧道自己取来，核对
  Lamplit 的发布签名，对上了才换，然后自己重启一下（电脑和手机一两秒内自动连回来）。
- **只运行签过名的程序**：签名用的是 Lamplit 发布用的那把密钥，私钥只在做发版的电脑上；公钥是你用 SSH 装中转时
  一起装进去的（`/opt/lamplit-relay`，只有 root 能改）。电脑只是「带话、送文件」，交给中转的东西签名对不上、
  被改过、或者比现在的旧，中转都不收。每次启动前中转还会再核对一遍。
- **新版本起不来就退回**：新版本 30 秒内没准备好，或者一分钟内就退出，中转会退回上一个版本，并记住这个版本不再试。
- **设置、加入密码、已登记的电脑都不动**：它们在数据目录（`/var/lib/private/lamplit-relay`）里，新版本也存在那里
  （`updates/`，最多两份）。
- **在哪里看**：设置 → 手机和外网 的中转卡片写「中转已更新到 x」「中转是最新的（x）」，或者没更新的原因；体检里有一行「中转更新」。
- **1.5.46 及以前装的中转**还不会自己更新：再点一次「重装 / 换端口」（最后一次手动），以后就自己更新了。
- **还是要「重装」的情况**：换端口、换服务器，或者以后某个版本要改 systemd 服务本身（会在更新说明里写）。

## 7. 旧版 App

只开了中转（电脑没有局域网地址）时，二维码以一句话开头：「请先更新 Lamplit App 再扫」。旧版 App 扫到会提示
「不是 Lamplit 的连接码」，不会再在列表里留下一台永远离线的机器；更新 App 后再扫即可。
