# 评测集（20 个日常任务 + 5 道难题）

每发一版，在发版的电脑上用真实模型跑一次，看这一版是变好了还是变差了。

```bash
npm run eval -- --record
```

## 怎么跑

- 20 个日常任务，五类各四个：**整理文件**、**填表**、**查资料出报告**、**收发邮件**、**定时简报**。任务和判分规则都在 `eval/tasks.mjs`。
- 5 道难题（1.5.14 起，`eval/hard.mjs`）：要走好几步、要上网查几样东西、或者不先问人就做不对。比如订团建场地没说人数和预算，要先问；清理下载文件夹时，明显的垃圾可以直接删，旧版安装包和草稿要先跟人提。
- **中途问人**：机器人回完一轮，评测脚本按题目替人回话（题目里的 `human`），再等它做完，最多四轮。每回一次记一次「中途问人」，和审批卡片分开算。该问的没问、没问就删了拿不准的东西，都算不及格。
- 每个任务给一个新建的临时机器人（自己的记忆，用量单独记账），工具只有 `EVAL_TOOLS` 里那些日常的：读写文件、命令、上网读网页、记忆、定时任务。没有发邮件、发文件、给别的机器人发消息。
- 每个任务一个新文件夹 `工作区/eval/<这次>/<任务>`，放好起始文件，然后像人一样发一句话。
- 机器人弹出审批卡片时，评测脚本代替人回答：读文件、在任务文件夹里写文件、建改定时任务、只在任务文件夹里动的命令，同意；别的拒绝。**每张卡片记一次人工干预**，不管同意还是拒绝。
- 做完后只看结果：文件夹里的文件、机器人的定时任务、它的回答。判分规则在冒烟测试里检查过：什么都不做一定不及格，正确结果一定及格。
- 跑完删掉临时机器人、它的定时任务和任务文件夹（`--keep` 保留文件夹）。
- 邮件题用 .eml 文件，不连真实邮箱，不会发出任何邮件。「上网查资料」那题会读 nodejs.org，取不到时这题不算。

只跑几个：`npm run eval -- --only f1-sort,m2-reply`；只跑难题：`npm run eval -- --hard`；`--verbose` 打出没过那题的每轮回复。单题超时默认 360 秒（`EVAL_TURN_SECONDS`）。

不碰日常用的那台：起一台一次性的测试实例，用 `EVAL_HUB=http://127.0.0.1:端口` 和 `EVAL_LOCAL_KEY=<那台 data\local-key 里的本机钥匙>` 指向它跑（1.5.51 的真模型评测就是这么跑的）。

审批档会改变卡片数量（「标准」下搬文件、删文件、上网、建定时任务都要问，「放手」下基本不问）：脚本开头读 `/api/policy`，在第一行和记录里写明「审批档」，不同档的「人工干预」不要直接比。
